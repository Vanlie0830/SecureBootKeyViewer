# v00.00.1a — 初版

## 新增功能

### UEFI 變數讀取 (collectors.py)
- 支援 PK、KEK、db、dbx 四個 Secure Boot 變數
- 雙重讀取方式：Win32 API (`GetFirmwareEnvironmentVariableW`) 優先，
  PowerShell (`Get-SecureBootUEFI`) 備援
- Secure Boot 狀態檢測：登錄檔 `UEFISecureBootEnabled` + `Confirm-SecureBootUEFI`
- 管理員權限偵測 (`IsUserAnAdmin`)

### EFI Signature List 解析 (parsers.py)
- 解析 `EFI_SIGNATURE_LIST` 二進位結構
- 支援簽章類型：X.509、SHA-1/256/384/512、RSA-2048
- GUID 小端序轉換 (`bytes_to_guid`)
- Hex dump 顯示工具

### X.509 憑證解析 (certs.py)
- 多重解析備援：cryptography → PowerShell .NET → 基本指紋
- 擷取 Subject、Issuer、Serial、有效期限、Thumbprint、簽章演算法、公鑰大小
- 憑證快取機制 (避免重複解析)

### Tkinter GUI (ui.py)
- GitHub Dark 設計系統（同 ModernStandbyTester 風格）
- 左側 200px 導覽側邊欄：總覽 / PK / KEK / db / dbx / 日誌
- 指標卡片：各變數簽章筆數統計
- 簽章列表 (Treeview) + 詳細面板 (Text)
- 背景執行緒載入 + 訊息佇列更新 UI

### 報告匯出 (report.py)
- Markdown 報告
- HTML 報告（GitHub Dark 主題）

### 測試
- tests/test_parsers.py：14 項測試全數通過
  - 版號管理（5 項）
  - EFI GUID 解析（2 項）
  - Signature List 解析（5 項）
  - Hex Dump（2 項）
