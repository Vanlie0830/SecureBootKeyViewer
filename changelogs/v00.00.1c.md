# v00.00.1c — UI 細節修正 + App Icon

## 修復

### 導覽圖示重複 (i18n.py)
- 日誌、設定、總覽的 i18n 字串原本包含 emoji 圖示
- nav_items 又另外傳入 icon，導致顯示兩個圖示
- 修正：移除 i18n 字串中的 emoji，只保留純文字

### 憑證長文字換行對齊 (ui.py)
- Subject/Issuer 等長值超過寬度時，原本換行後貼齊最左邊
- 修正：使用 textwrap.fill + subsequent_indent 自動對齊值欄位
- 視覺效果：換行文字與首行值對齊，閱讀更舒適

## 新增

### 應用程式 Icon (sbkv/app_icon.ico)
- 深藍盾牌象徵安全防護
- 金色鑰匙孔代表 Secure Boot Key
- 綠色勾勾 = 已驗證/受信任
- SBK 文字標識
- 支援 256/128/64/48/32/16 多尺寸
- PyInstaller --icon 參數套用
