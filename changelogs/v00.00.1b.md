- 純文字格式，60 字元分隔線排版
- 匯出對話框新增 .txt 選項

- UI 介面風格：暗色系 / 亮色系 / 系統設定 (三選一按鈕)
- UI 語言：繁體中文 / English (二選一按鈕)
- 版權資訊顯示於設定頁底部
- 切換後立即生效 (重建 UI)

### 主題系統 (sbkv/themes.py) — NEW
- DARK: GitHub Dark (#0d1117 系列)
- LIGHT: GitHub Light (#ffffff 系列)
- SYSTEM: 讀取 Windows 登錄檔 AppsUseLightTheme 偵測
- `resolve_theme(mode)` 統一入口

### 多語系系統 (sbkv/i18n.py) — NEW
- 支援 zh-TW (繁體中文) / en (English)
- 60+ 翻譯字串
- `t(key, lang)` 統一入口
- 報告匯出同步多語系

### 報告匯出多語系 (report.py)
- export_html / export_markdown / export_text 均支援 lang 參數
- 依 UI 當前語言輸出報告
